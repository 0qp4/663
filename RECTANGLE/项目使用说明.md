## 项目概述

本项目是一个基于 **SAT（布尔可满足性）求解器** 的差分密码分析框架，专门用于对 **RECTANGLE** 轻量级分组密码进行安全性评估。

### RECTANGLE 密码简介

RECTANGLE 是由 Zhang 等人于 2015 年设计的轻量级分组密码，具有以下特点：

| 版本 | 分组长度 | 密钥长度 | 轮数 |
|------|---------|---------|------|
| RECTANGLE-64/80 | 64 位 | 80 位 | 25 轮 |
| RECTANGLE-64/128 | 64 位 | 128 位 | 25 轮 |

密码结构采用 **代换-置换网络（SPN）**：
- **S 盒层（SubCells）**：使用 4-bit S 盒进行非线性变换
- **置换层（ShiftRows）**：按行进行位移操作
- **密钥加层（AddRoundKey）**：与轮密钥进行异或操作

## 功能特性

### 1. 相关密钥差分分析（Related-Key Differential Analysis）

这是本项目的**核心功能**，通过 `KEY_NOT_ZERO` 约束分析密钥差分：

```python
trails = diff_attacks(
    cipher,
    goal='DIFFERENTIALPATH_PROB',
    constraints=['INPUT_NOT_ZERO', 'KEY_NOT_ZERO'],  # 关键约束
    objective_target='OPTIMAL',
    config_model={'model_type': 'sat'},
    config_solver={'solver': 'Cadical195'},
)
```

### 2. 最小活跃 S 盒计数（Minimum Active S-box Counting）

统计最小活跃 S 盒数量，用于评估密码抗差分攻击能力：

```python
trails = diff_attacks(
    cipher,
    goal='DIFFERENTIAL_SBOXCOUNT',
    constraints=['INPUT_NOT_ZERO'],
    objective_target='OPTIMAL',
    config_model={'model_type': 'sat'},
    config_solver={'solver': 'Cadical195'},
)
```

### 3. 多轮渐进分析（Multi-Round Progressive Search）

从 1 轮到 N 轮渐进搜索：

```bash
python main.py --multi-round 1 15
```

## 安装配置

### 环境要求

- **Python**: 3.8+
- **SAT 求解器**: Cadical（推荐）、Lingeling、Glucose 等

### 步骤 1：安装 Python 依赖

```bash
cd RECTANGLE
pip install -r requirements.txt
```

主要依赖：
| 包 | 用途 |
|----|------|
| numpy | 数值运算 |
| python-sat (pysat) | SAT 求解器接口 |

### 步骤 2：安装 SAT 求解器（推荐 Cadical）

**方法 A：下载预编译二进制**

从 [Cadical 发布页](https://github.com/arminbiere/cadical/releases) 下载并添加到系统 PATH。

**方法 B：从源码编译**

```bash
git clone https://github.com/arminbiere/cadical.git
cd cadical
mkdir build && cd build
cmake ..
make
# 添加到 PATH 或当前目录
```

### 步骤 3：验证安装

```bash
python main.py --rounds 4
```

## 快速开始

### 命令行使用

```bash
# 相关密钥差分分析（默认模式）
python main.py --mode related-key --rounds 8

# 最小活跃S盒搜索
python main.py --mode active-sbox --rounds 8

# 多轮范围搜索（自动渐进分析）
python main.py --mode related-key --rounds 8-12
python main.py --mode active-sbox --rounds 1-10

# 显示模式（0: 无输出, 1: 简洁, 2: 详细, 3: 完整）
python main.py --mode related-key --rounds 8 --show-mode 2

# 设置起始权重值（AT LEAST 优化模式，加速搜索）
python main.py --mode related-key --rounds 10 --start-weight 15

# 设置输出目录（结果保存到 files/{name}，不存在则自动创建）
python main.py --mode related-key --rounds 8 --output-dir my_results
python main.py --mode active-sbox --rounds 8 --output-dir sbox_analysis

# 其他选项
python main.py --version 64_128 --rounds 8 --mode active-sbox
python main.py --solver Cadical195 --mode related-key --rounds 8
```

### Python 脚本使用

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parent))

from primitives.rectangle import RECTANGLE_BLOCKCIPHER
from attacks.attacks import diff_attacks

# ===== 相关密钥差分分析 =====
cipher = RECTANGLE_BLOCKCIPHER(r=8, version=[64, 80])

trails = diff_attacks(
    cipher,
    goal='DIFFERENTIALPATH_PROB',
    constraints=['INPUT_NOT_ZERO', 'KEY_NOT_ZERO'],  # 相关密钥约束
    objective_target='OPTIMAL',
    show_mode=0,
    config_model={'model_type': 'sat'},
    config_solver={'solver': 'Cadical195'},
)

if trails:
    trail = trails[0]
    print(f"差分权重: {trail.data['diff_weight']}")
    print(f"概率: {2**(-trail.data['diff_weight']):.6e}")


# ===== 最小活跃 S 盒搜索 =====
cipher = RECTANGLE_BLOCKCIPHER(r=10, version=[64, 80])

trails = diff_attacks(
    cipher,
    goal='DIFFERENTIAL_SBOXCOUNT',
    constraints=['INPUT_NOT_ZERO'],
    objective_target='OPTIMAL',
    show_mode=0,
    config_model={'model_type': 'sat'},
    config_solver={'solver': 'Cadical195'},
)

if trails:
    print(f"最小活跃 S 盒数: {trail.data['diff_weight']}")


# ===== 使用输出目录 =====
trails = diff_attacks(
    cipher,
    goal='DIFFERENTIALPATH_PROB',
    constraints=['INPUT_NOT_ZERO', 'KEY_NOT_ZERO'],
    objective_target='OPTIMAL',
    show_mode=0,
    config_model={
        'model_type': 'sat',
        'output_dir': 'files/my_results'  # 自定义输出目录
    },
    config_solver={'solver': 'Cadical195'},
)


# ===== 使用 AT LEAST 模式加速搜索 =====
cipher = RECTANGLE_BLOCKCIPHER(r=10, version=[64, 80])
trails = diff_attacks(
    cipher,
    goal='DIFFERENTIALPATH_PROB',
    constraints=['INPUT_NOT_ZERO', 'KEY_NOT_ZERO'],
    objective_target='AT LEAST 15',  # 从权重15开始搜索
    show_mode=0,
    config_model={'model_type': 'sat'},
    config_solver={'solver': 'Cadical195'},
)
```

## 使用说明

### 核心函数

#### `diff_attacks()`

差分攻击主函数，位于 `attacks/attacks.py`。

**参数说明：**

| 参数 | 类型 | 说明 | 可选值 |
|------|------|------|--------|
| `mode` | str | 分析模式 | `'related-key'`, `'active-sbox'` |
| `rounds` | int/str | 轮数，支持单个值或范围 | `8`, `'8-12'` |
| `version` | str | 密码版本 | `'64_80'`, `'64_128'` |
| `show_mode` | int | 显示模式 | `0`, `1`, `2`, `3` |
| `start_weight` | int | 起始权重值 | `None`, `15` 等 |
| `solver` | str | SAT求解器 | `'Cadical195'` 等 |
| `output_dir` | str | 输出目录（相对于 files/） | `None`, `'my_results'` |

**约束选项（constraints）：**

| 约束 | 说明 |
|------|------|
| `'INPUT_NOT_ZERO'` | 明文差分非零（几乎总是需要） |
| `'KEY_NOT_ZERO'` | 密钥差分非零（相关密钥分析） |

### objective_target 选项

### SAT 求解器选项

| 求解器 | 说明 |
|--------|------|
| `Cadical195` | 推荐，开源高效 |
| `Cadical153` | Cadical 旧版本 |
| `Lingeling` | 强性能 |
| `Glucose4` | Glucose 系列 |
| `Minisat22` | 经典求解器 |

### `RECTANGLE_BLOCKCIPHER()` 构造函数

创建 RECTANGLE 密码实例。

```python
RECTANGLE_BLOCKCIPHER(
    r=None,                    # 轮数，None 表示 25 轮
    version=[64, 80],          # 版本：[64, 80] 或 [64, 128]
    represent_mode=0,          # 表示模式
    copy_operator=False,       # 是否复制操作符
    final_key_addition=True     # 是否包含最终密钥加
)
```

## 常见问题

### Q1: 求解时间过长怎么办？

**解决方案：**
1. 减少分析轮数
2. 使用更快的求解器（如 Cadical195）
3. 设置时间限制

```python
config_solver = {
    'solver': 'Cadical195',
    'time_limit': 3600  # 1 小时
}
```

### Q2: 遇到 UNSAT 怎么办？

UNSAT 表示在给定约束下不存在差分路径。可能原因：
1. 轮数太多导致无有效路径
2. 约束条件过于严格
3. 需要更多轮密钥信息

**尝试：**
- 减少轮数
- 检查约束设置
- 使用更宽松的优化目标

### Q3: 如何解读差分权重？

差分权重 \(w\) 与概率 \(p\) 的关系：

$$p = 2^{-w}$$

例如：权重 10 表示概率约为 \(2^{-10} \approx 9.77 \times 10^{-4}\)

### Q4: 活跃 S 盒数量有什么意义？

活跃 S 盒数量是评估分组密码抗差分攻击的重要指标：
- **越多越好**：更多活跃 S 盒意味着更强的非线性扩散
- **安全界限**：通常需要足够的活跃 S 盒数才能抵抗已知攻击

## 技术细节

### SAT 建模流程

```
1. 密码建模
   └─> 变量定义
   └─> 约束生成（S 盒、置换、密钥加）

2. 目标函数
   └─> 差分权重最小化 / 活跃 S 盒计数

3. SAT 求解
   └─> CNF 编码
   └─> 调用求解器（Cadical 等）

4. 解码分析
   └─> 提取差分路径
   └─> 格式化输出
```

### RECTANGLE S 盒

RECTANGLE 使用 4-bit S 盒：

```python
Sbox = [0x6, 0x5, 0xC, 0xA, 0x1, 0xE, 0x7, 0x9,
        0xB, 0x0, 0x3, 0xD, 0x8, 0xF, 0x4, 0x2]
```
